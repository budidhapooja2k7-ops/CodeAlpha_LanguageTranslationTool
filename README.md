# 🌐 Language Translation Tool

A simple web-based language translation tool built using **Python, Flask, and Deep Translator**.

## ✨ Features

- 🌍 Automatic source-language detection
- 🔤 Translation into different languages
- 📝 Easy-to-use text input
- 📋 Copy input and translated text
- 🔊 Listen to translated text
- 🌓 Light and dark mode
- 📱 Clean and responsive user interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Deep Translator
